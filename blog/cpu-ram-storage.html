What CPU, RAM and storage mean

CPU (processor)

The processor runs apps and the system. The number of cores and the architecture (for example ARM64) describe how it works. More cores help with several tasks at once. A newer design usually does more work per watt.

RAM (memory)

RAM holds apps you are using right now. More RAM lets you switch between apps without reloading them. It is not the same as storage.

Storage

Storage keeps your files, apps and photos when the phone is off. Free space matters: a nearly full storage can slow down updates and the system.
