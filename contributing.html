Translate

Translations live in the translation table in js/app.js. Each language is one block with the same keys in the same order.

Steps

  1. Copy the English block and rename it with the language code (for example pl for Polish).
  2. Translate the values. Keep the keys and any HTML tags such as <em> and <br>.
  3. Add the code to the language selector in settings.html and index-html4.html.
  4. Open an issue or pull request on GitHub with the change.

Please check that the text fits on a small phone screen.
