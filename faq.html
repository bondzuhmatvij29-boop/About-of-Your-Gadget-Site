Frequently asked questions

Why does Android ask me to allow installing from unknown sources?

The app is installed from an APK file, not from the Google Play Store, so Android asks you to confirm it. You only need to allow it for the browser or file manager you used to download the file.

Is it safe?

The source code is public on GitHub, so anyone can check what the app does. Download it only from the links on this site.

How do I update the app?

Download the newest APK from APKPure or the GitHub releases page and install it over the old version. See the changelog for what changed.

Why does some information say “unknown”?

Android does not expose every value to apps. Some phones, especially older or heavily customized ones, hide certain sensors or battery details, so the app shows “unknown” instead of a guess.

Something is wrong. Where do I report it?

Open an issue on GitHub Issues. Include your phone model and Android version.
